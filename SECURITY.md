# Security Policy

## Reporting a Vulnerability

We take security and secret hygiene seriously.

If you believe you have discovered a vulnerability, security flaw, or exposed credential in this project:

1. **Please do not open a public GitHub issue.**
2. Send an email to the repository maintainer with details regarding the issue and steps to reproduce.
3. Allow reasonable time for the issue to be assessed and addressed before any public disclosure.

Thank you for helping keep the project safe for everyone.
